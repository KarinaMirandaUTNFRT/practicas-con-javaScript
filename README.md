Prácticas de JavaScript 

Este repositorio contiene una serie de ejercicios prácticos diseñados para dominar los fundamentos de la programación con JavaScript, enfocándose en la manipulación de datos, estructuras de control y salida por pantalla.

Contenido del Proyecto

El proyecto está organizado en una carpeta de ejercicios numerados para facilitar el seguimiento del aprendizaje:

01-mostraNombre.js: Interacción básica con el usuario mediante prompt y alert.

02-SumaDosNumeros.js: Uso de parseInt() para transformar entradas de texto en datos numéricos y realizar operaciones aritméticas.

03-multiplicarPorDiez.js: Operaciones matemáticas simples y constantes.

04-convertirGradosAFahrenheit.js: Aplicación de fórmulas matemáticas para conversión de unidades.

05-calcularPerimetroArea.js: Lógica geométrica aplicada al código.


Tipado de datos: Implementación de parseInt para evitar errores de concatenación de strings.

Document Object Model (DOM): Uso de document.write y document.writeln para renderizar resultados.

Template Literals: Uso de comillas invertidas (`) para una interpolación de variables más limpia y profesional.
